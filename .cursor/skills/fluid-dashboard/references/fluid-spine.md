# The Fluid Spine — Worked Examples
Core: Customer Interaction → Signal → Business Issue → Persona Owner → Evidence → Recommended Action
Conduct: Obligation → Customer Contacts → Channel Signals → Met % → Evidence → Owner Action

- Service call → "issue repeated 3 times" → unresolved service failure → Head of CX → timestamped snippet → fix queue/agent/journey
- Complaint → asks to escalate, no SR created → complaint-capture gap → Head of Contact Centre/CX → transcript + missing ticket → coach queue + auto-tag (a missed complaint starts a 30-day clock under RB-IOS 2026)
- Product call → optional add-on described as mandatory → product conduct risk (bundling) → Head of Product/Digital → snippet + campaign ID → fix script + pause campaign
- Recovery call → pressure language, call outside permitted hours → recovery conduct breach → CRO → snippet + timestamp + vendor/location → vendor remediation + breach escalation
